# 纸上交锋 · PAPER STRIKE

**[在线试玩 →](https://moeyui1.github.io/CS-on-paper/)** · [源码](https://github.com/moeyui1/CS-on-paper) · [技术文档](docs/TECHNICAL.md) · [Prompt 参考](RECREATE_PROMPT.md)

一个单人、单关卡的网页 3D 第一人称射击 Demo。在涂鸦本般的「日光街区」，用纸板枪与大头小豆人交战。暖黄、橘红、青绿配色，搭配手绘轮廓和漫画反馈。

## 项目说明

本项目由 **Deepseek harness + deepseek v4.1 flash** 开发完成。

**仅供参考，不再更新或维护。** 本仓库与在线 Demo 保留为开发实验与学习参考，不提供后续功能迭代、问题修复或性能保证。

## 玩法

- 清除训练场中的 **8 名敌人**即可获胜；生命值归零则失败。
- 开局生命值 **100**，无自动恢复，利用木箱、矮墙和建筑躲避攻击。
- 随身携带**蜂鸟冲锋枪**与**长鸣狙击枪**，可在准备页选择开场装备。
- 弹匣有限、备弹无限，打空仍需换弹；狙击枪支持 **4 倍镜**。
- 中央庭院连接左右侧路，东侧高台提供不同的交火角度。

## 操作

推荐使用桌面版 Chrome / Edge，以及键盘和鼠标。

| 操作 | 输入 |
| --- | --- |
| 移动 | `W` `A` `S` `D` |
| 观察 | 鼠标移动 |
| 射击 | 鼠标左键 |
| 瞄准 | 按住鼠标右键 |
| 跳跃 | `Space` |
| 换弹 | `R` |
| 切枪 | `1` / `2` 或滚轮 |
| 暂停、释放鼠标 | `Esc`，或顶部暂停按钮 |
| 静音 / 开启音效 | 顶部音效按钮 |

若浏览器不允许锁定鼠标，会自动提供**兼容模式**：拖动鼠标或用方向键观察，`F` 射击，`T` 切换瞄准。移动、跳跃和换弹不变。建议直接打开试玩页面，而非在内嵌预览中游玩。
